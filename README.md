### 🌱 CropScan
**Offline Crop Disease Detection on Android**

`Python` `TensorFlow` `MobileNetV2` `TensorFlow Lite` `Flutter`

A mobile-first computer vision application that performs crop disease diagnosis directly on-device.

**Highlights**
- 🧠 MobileNetV2 transfer learning
- 📱 Offline Android inference
- ⚡ TensorFlow Lite deployment
- 🗜️ Dynamic-range quantization
- 🌾 38 disease classes across 14 crops
- 🔒 No network dependency
- ⚡ ~180–220 ms inference on mid-range Android
- 📦 Model reduced from 8.9 MB → 2.4 MB

**Validation accuracy:** 93.60%

🔗 [View Project](https://github.com/priyanshu-1git/crop_app)
